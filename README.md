# 📋 Gestão de Presença e Faltas

## 🎯 Objetivo
Projeto simples em Python feito para praticar lógica de programação, uso de listas, dicionários e salvamento de dados em arquivo de texto (.txt). O programa cadastra o ponto dos funcionários com nome, data e status (presente ou falta), exibe o histórico de lançamentos na tela e salva um relatório final em um arquivo de texto no computador.

## 🛠️ Tecnologias
- 🐍 Python 3
- 💻 VS Code
